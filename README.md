# ODONTOCLINIC

Landing page em HTML, CSS e JavaScript, com imagens e fonte locais.

Abra index.html no navegador ou publique esta pasta em uma hospedagem estática. Não requer instalação nem compilação.

## Contato
Preencha WHATSAPP_NUMBER em script.js com o número oficial, incluindo país e DDD, apenas dígitos. O contato está vazio e não envia mensagens até ser configurado.

Substitua o endereço demonstrativo e seu mapa em index.html pelos dados reais. Imagens ilustrativas, não representam equipe ou pacientes reais.
